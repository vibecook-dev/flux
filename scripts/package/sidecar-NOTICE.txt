================================================================================
bin/sidecar-slim: Truffle's Tailscale sidecar
================================================================================

bin/sidecar-slim is the unmodified sidecar binary from a Truffle release
(https://github.com/vibecook-dev/truffle/releases, built from
packages/sidecar-slim at that release's tag). It is a Go program built with
Tailscale's tsnet. The licences of the code it contains follow. The complete
list of Go modules in it is packages/sidecar-slim/go.mod at the release tag,
and `go version -m bin/sidecar-slim` prints the exact module versions; those
modules are under the MIT, BSD-2-Clause, BSD-3-Clause, Apache-2.0 and ISC
licences, whose texts appear in this file.
